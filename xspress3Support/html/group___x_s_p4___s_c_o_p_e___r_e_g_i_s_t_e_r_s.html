XSPRESS3-Mini and XSPRESS4 scope mode control registers
Macros for XSPRESS3 » Macros to describe features enabled in current firmware build » servo features » Global register in ADC Clock domain

Topics

 XSPRESS4 scope mode data source select values.
 This data is assembled nibble at a time into the 32 bit hardware registers XSP4_GLOB_SCOPE_SRC_SEL0 and XSP4_GLOB_SCOPE_SRC_SEL1 using XSP4_GSCOPE_SRC_SEL[XSP4_SCOPE_SOURCE_CODE].
 XSPRESS3-Mini scope mode data source select values.
 This data is assembled nibble at a time into the 32 bit hardware registers XSP4_GLOB_SCOPE_SRC_SEL0 and XSP4_GLOB_SCOPE_SRC_SEL1 using XSP4_GSCOPE_SRC_SEL.
