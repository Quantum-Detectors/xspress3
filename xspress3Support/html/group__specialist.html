Set the location of the data module, calibrator pulse histogram buffer and buffer size in the xspress3 system.

This data module should be present before initialising the histogramming threads and remain in context until after the threads have been terminated.

Parameters
patha handle to the top level of the xspress3 system returned from xsp3_config().
chanis the number of the channel in the xspress3 system, 0 to (xsp3_get_num_chan() - 1)
modulea pointer to the data module
mod_headPointer to return pointer module header information.
buffera pointer to the data buffer within the data module
bufsizthe size of the buffer
Returns
XSP3_OK or a negative error code.

int xsp3_set_data_buffer ( int path,
int chan,
u_int32_t * buffer,
u_int32_t bufsiz )

Set the location of the histogram buffer and buffer size in the xspress3 system.

This is provided if the default shared memory buffers are not th be used, which will be difficult to implement. This buffer should be present before initialising the histogramming threads and remain in context until after the threads have been terminated.

Parameters
patha handle to the top level of the xspress3 system returned from xsp3_config().
chanis the number of the channel in the xspress3 system, 0 to (xsp3_get_num_chan() - 1)
buffera longword pointer to the location of the buffer
bufsizthe size of the buffer
Returns
XSP3_OK or a negative error code.
