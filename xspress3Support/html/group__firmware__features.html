Detailed Description

To track development of the algorithm and to allow additional features to be removed to get higher channel count builds to fit, the VHDL code is written to allow features to be configured in or out.

The VHDL constants which do this also automatically build a set of 3x32 bit "features" registers split into 3x8 4 bit fields. This code allow these fields to be interrogated to determine whether a given feature is present.
The functions of most interest to use code are xsp3_has_itfg(), xsp3_get_generation() and xsp3_has_roi().
